# celinki-web

Sitio de Celinki en [celinki.com](https://celinki.com): muestrario de accesorios para celular, pedidos por WhatsApp y micas de hidrogel a mayoreo.

- Astro, publicado en GitHub Pages con `.github/workflows/deploy.yml` en cada push a `main`.
- Dominio: `public/CNAME`; DNS en Namecheap (ver `docs/PLAN.md`, sección 5).
- Plan y fases: [`docs/PLAN.md`](docs/PLAN.md).

Local (opcional): `npm install && npm run dev`.
